
# Monitor inteligente de cadena de frío

Proyecto final de la asignatura Sistemas Inteligentes.

## Objetivo

Desarrollar un sistema de monitoreo de temperatura basado en ESP32 para supervisar las condiciones de transporte de productos que requieren cadena de frío y planificar las rutas de distribución con algoritmos de soluciones óptimas (idea: wokwi y PlatformIO).

## Componentes del proyecto

1. Electrónica y adquisición de temperatura.
2. Calibración de sensores mediante regresión matricial.
3. Modelo matemático de calentamiento del contenedor.
4. Detección de anomalías mediante SVD y PCA.
5. Planeación de rutas mediante algoritmos de optimización.
6. Integración del sistema en ESP32.
